AUDIT HANDOFF AND LIMITATIONS
============================================================================
Design order: CPU, RAM, Notifications, Battery, Clock (left to right).
Visual target: top horizontal panel, 32-36 px initial height, dark translucent, minimal radius, subtle shadow.
Visibility target: always visible, all monitors; fullscreen behavior requires runtime verification.
Notification interaction: icon click opens a notification tray/panel; tray is not permanently open.
Still to decide from evidence: QML integration point, data providers, tray implementation/API, sizing/layout, locale/time format, exclusive zone, focus/fullscreen, hotplug/scaling.
This audit does not compile QML, prove API compatibility, send notifications, alter services, or verify visual behavior.
QML discovery is a bounded static scan; candidate relative paths and recognized identifiers are leads, not proof of the active entry point.
Configuration source contents, source lines, comments, literals, process arguments, environment variables, serial numbers, and absolute home paths are never published.
Review findings before writing the separate implementation/deployment script.
