# K41 Obsidian Minimalism — Design System

**Identitas:** K41 Obsidian Minimalism  
**Palet:** Graphite Monochrome  
**Status arah desain:** APPROVED

Dokumen ini mendefinisikan bahasa visual lintas-komponen untuk desktop ThinkPad X280. Ia menjelaskan apa yang harus dibangun, bukan status runtime atau prosedur deployment.

## Peta dokumen

- [01 — Foundations](01-FOUNDATIONS.md): identitas, warna, tipografi, ikon, layout, motion, wallpaper, performa.
- [02 — Components](02-COMPONENTS.md): tujuan dan perilaku komponen desktop.
- [03 — Decisions](03-DECISIONS.md): keputusan yang disetujui, batas, dan hal yang masih terbuka.

## Aturan penggunaan

1. Gunakan dokumen ini sebagai acuan desain bersama untuk seluruh Stage 5.
2. Setiap komponen hanya mengimplementasikan bagian yang relevan; jangan membuat ulang komponen upstream tanpa kebutuhan.
3. Hindari menduplikasi token atau keputusan di dokumen workstream.
4. Perubahan material pada identitas, token, atau perilaku lintas-komponen harus dicatat di Decisions.
5. Status IMPLEMENTED/TESTED/VERIFIED bukan bagian dari spesifikasi desain; lihat [status proyek](../06-STATUS.md).
6. Review visual dilakukan langsung oleh pengguna pada X280. Screenshot tidak digunakan.
